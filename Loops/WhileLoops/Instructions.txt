Instructions:
    -You will be building up from Switch Case project where you will be making a program where
    you ask the user which command to give the robot and the commands will be executed in sequential
    order, given that conditions have been met..
    For example:
        If you start the program and select intake you will have to first drive to get fuel
        If you try to shoot and there is no fuel in the robot then it will say it cannot shoot
        etc.
    -You will first create a variable that tells the program whether or not the user wants to continue
    -You will then create 2 variables, one that stores where the robot is currently at,it will have 
    2 locations GamePiece, and Goal. And the other will say if there are game pieces in the robot or
    not (the amount of fuel does not matter, just whether or not it is inside)
    -You will then make the while loop that stores the following things
        -Asking the user which command they want to use
        -Switch cases that matches the command
            -Inside those commands you will check some conditions based on the tasked
Objectives:
    -Ability to use a while loop when it is necessary
    -Ability to make sure the while loop has an exit
    -Be able to use switch cases with if statements inside of them
